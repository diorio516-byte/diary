# 이미지 작업 프로세스 — 사진이 들어간 안내서·PDF·카드 만들기

> 2026-10-23 "대전 데이트 토요일 코스 3컨셉" PDF(4쪽 · 장소 사진 12장)를 만들며 굳힌 순서.
> 이 문서는 **Claude(코드 창 · 코워크 · 채팅)가 읽고 그대로 따르는 작업 지시서**다.
> 재준이 사진을 따로 말하지 않아도, 장소·코스·추천·집 후보·제안서·설명서처럼 사진이 들어갈 만한 결과물이면 **이 순서대로 사진까지 넣는다**('글만'이라고 할 때만 뺀다). 스크립트는 `tools/photo_pipeline/`.

---

## 0. 한눈에

```
① 글 먼저 확정 → ② 조사(장소·평점·영업시간·사진 URL) → ③ 사진 가져오기(A 직접 / B Canva 우회 / C 영상 캡처)
→ ④ 조판(HTML → PDF) → ⑤ 미리보기 눈으로 확인 → ⑥ 전달(파일 하나 · 여러 개면 zip)
```

지킬 원칙 5개
0. **알아서.** "사진 넣어 줘"라는 말을 기다리지 않는다. 결과물이 안내서·PDF·카드면 사진은 기본이고, 글만 먼저 보내고 사진 판을 이어서 보내도 된다.
1. **글이 먼저, 사진은 나중.** 사진이 없다고 시간표·주소·영업시간을 바꾸지 않는다. 사진이 안 구해지면 그 자리는 '정보 카드'(평점·리뷰 한 줄·영업시간)로 채우고 나중에 바꾼다.
2. **승인 두 번.** 만들기 전에 방향(컨셉·쪽 구성)을 글로 보여 주고 `ㄱ`을 받는다. 다 만든 뒤에는 컨택트시트(전 쪽 한 장)를 Claude가 먼저 보고 넘침·겹침을 고친 다음 보낸다.
3. **출처는 꼭.** 바닥글에 "사진: 구글 지도 이용자 사진(개인 참고용)"처럼 한 줄. 사진마다 제공자(attribution)를 알면 `photos.json`에 적어 둔다.
4. **막히면 우회, 되풀이 금지.** 다운로드가 403으로 막히면 같은 주소를 다른 명령으로 다시 시도하지 말고 바로 3-B(Canva 우회)로 간다.

## ① 글(내용) 먼저

- 시간표 · 장소 · 주소 · 전화 · **그 요일 영업시간 · 휴무** · 가격을 먼저 확정한다. (예: 토요일 일정이면 '월 휴무'인 곳은 괜찮고 '토 예약 불가'는 표에 적는다.)
- 바뀔 수 있는 숫자(영업시간 · 기차 시각)는 본문에 "당일 아침 네이버 지도/코레일톡으로 한 번 더 확인" 한 줄을 넣는다.
- 쪽 구성 기본형(A4 세로)
  - 표지: 제목 · 공통 일정(픽업 → 이동 → 휴식 → 저녁 → 복귀) · 선택지 표 · 체크리스트
  - 본문 1쪽 = 컨셉 1개: 왼쪽 **시간표 표(116mm)** + 오른쪽 **사진 칸(64mm · 6장)** + 아래 팁 상자 + 바닥글(출처)
- 이 단계에서 글만 들어간 판을 먼저 보내도 된다(사진 자리는 점선 박스). 재준이 기다리는 시간을 줄인다.

## ③ 사진 가져오기 — 환경에 따라 셋 중 하나

### 3-A. 직접 내려받기가 되는 곳 (코워크 · 내 컴퓨터의 코드 창)
```bash
mkdir -p raw && curl -sL "<사진 URL>" -o raw/jangtaesan.jpg
```
- 가로 800px 이상이면 충분. 파일 이름은 영문 slug(`oncheon_kalguksu.jpg`).

### 3-B. 내려받기가 막힌 곳 (클라우드 샌드박스 · 403 '정책 거부') — **검증된 우회**
증상: `curl`/파이썬으로 lh3.googleusercontent.com · wikimedia · unsplash · export-download.canva.com 모두 403, `WebFetch`는 글만 주고 이미지는 못 받음. 이때는 **Canva 연결(MCP)을 사진 운반 통로**로 쓴다. Canva는 외부 URL에서 사진을 받아 주고, 편집 응답의 **페이지 미리보기(썸네일)가 로컬에 PNG로 저장**되기 때문이다.

순서 (사진 12장 기준 10분 안팎 · 호출 7~8번)
1. `upload-asset-from-url` — 사진 URL마다 한 번 → asset id(`MAHY…`). 이름은 장소 이름으로.
2. 디자인 하나를 편집 상태로 연다: 아무 디자인에 `read-design`(`open_transaction: true`, `filter.fields: ["design_metadata"]`) → `transaction_id`. 디자인이 없으면 `create-design`(Document A4)으로 하나 만든다.
3. `edit-design` **add_page** — 사진 비율대로 **긴 변 1600px** 페이지를 사진 수만큼(한 호출에 여러 개 OK).
   - 가로 800×534 → 1600×1067 · 가로 800×600 → 1600×1200 · 세로 450×600 → 1200×1600 · 정사각 → 1600×1600
   - 사진 크기는 `get-assets`(metadata.width/height)로 확인.
4. `read-design`(`transaction_id`, `filter.fields: ["design_content"]`, `page_indices: [새 쪽들]`) → 각 `page_id`. (`page_metadata`는 저장 전 쪽을 못 보니 쓰지 않기)
5. `edit-design` **insert_fill** — 쪽마다 `{page_id, asset_type:"image", asset_id, top:0, left:0, width, height}`(쪽 크기와 같게). 여러 쪽을 한 호출에 넣어도 된다(`page_index`는 그중 하나).
6. 썸네일 받기
   - `edit-design` 응답의 썸네일 = **긴 변 600px**(`page_index`로 지정한 쪽 하나).
   - `read-design`(`filter.fields: ["thumbnails"]`, `thumbnail_pages: [...]`) = 여러 쪽을 한 번에 받지만 **338~600px로 들쭉날쭉**.
   - 600px이 꼭 필요한 쪽은 `edit-design`에 무해한 편집 하나(`replace_speaker_notes`)를 보내면 그 쪽 썸네일이 600px로 온다.
7. 받은 썸네일은 자동으로 로컬에 저장돼 있다: `~/.claude/projects/<작업폴더>/<세션>/tool-results/mcp-Canva-blob-<밀리초>-xxxx.png` → `python3 tools/photo_pipeline/collect_canva_thumbs.py --since 15 이름1 이름2 …`(받은 순서대로 이름 붙여 `raw/`에 복사).
8. 다 받았으면 `edit-design`(`finalize: "cancel"`)로 임시 쪽을 버린다. (디자인 자체를 남길 땐 재준 승인 뒤 `commit`.)

한계와 팁
- 600px = 64mm 폭에 약 240dpi. 폰 · A4 인쇄용으로 충분, **전면 사진에는 부족**.
- Canva `get-assets` 썸네일은 200px이라 못 쓴다.
- Canva AI 생성 디자인(`create-design`)은 한글 글자가 자주 깨지므로(예: 칼국수 → 할국수) 글은 이 문서의 HTML 조판으로 하고, Canva는 사진 운반에만 쓴다.

## ④ 조판 — HTML → PDF

- 템플릿: `tools/photo_pipeline/template_a4.html` (표지 1쪽 + 컨셉 쪽 형태 · CSS 포함). 글은 여기에 채운다.
- 사진 칸 규칙
  - 고정 비율 프레임 `.pf` **64×37mm**(가로 사진) · 세로 사진은 두 장 나란히 `.pgrid` **31×37mm**.
  - wkhtmltopdf에는 `object-fit`이 없다 → `crop_photos.py`가 PIL로 프레임 비율에 맞춰 **센터 크롭**한 뒤 `width:100%; height:100%`로 넣는다.
  - 캡션은 사진 위 반투명 띠 `.pl`(rgba(0,0,0,.58) · 8.3pt · **한 줄**로 짧게 — 두 줄이면 줄인다).
  - 6칸(37mm×6 + 간격 4mm×5 = 242mm)이 본문 1쪽의 사진 칸에 딱 맞는다. 7장 이상이면 세로 사진 짝짓기로 줄인다.
- 자리 표시: HTML에 `<!--PHOTO:slot_name-->` 한 줄(또는 옛 형식 `<div class="placeholder"><span>…img/slot_name.jpg…</span></div>`). `build_pdf.py`가 `job.json`을 보고 사진 블록으로 바꾼다.
- 변환(wkhtmltopdf · 검증됨)
  ```bash
  wkhtmltopdf --quiet --page-size A4 --orientation Portrait \
    --margin-top 0 --margin-bottom 0 --margin-left 0 --margin-right 0 \
    --encoding utf-8 --enable-local-file-access _wk.html "결과.pdf"
  ```
  - **mm 보정 필수**: 이 환경의 wkhtmltopdf는 210×297mm 상자를 78% 크기로 그린다 → 변환용 사본 `_wk.html`에만 `body { zoom: 1.282; }`를 넣는다(원본 HTML엔 넣지 않기 · 크롬 인쇄용은 원본).
  - 한글 글꼴: `"Noto Sans CJK KR"`(`/usr/share/fonts/opentype/noto/`). 없으면 `fc-list | grep -i cjk`로 찾고, 없으면 `apt-get install fonts-noto-cjk`.
  - `--disable-smart-shrinking` · `--print-media-type`은 이 환경(unpatched qt)에서 무시된다는 경고가 뜨지만 해롭지 않다.
- 쓰지 말 것: reportlab + Noto CJK OTF → `postscript outlines are not supported`로 실패. (TTF 글꼴이 따로 있을 때만 reportlab.)
- 대안: Chromium(playwright) `page.pdf(format="A4", print_background=True)` — zoom 보정이 필요 없다(이 작업에선 미검증).

## ⑤ 미리보기 확인 (보내기 전에 Claude가 먼저 본다)

```bash

pdftoppm -r 40 -png 결과.pdf all        # 전 쪽 PNG
```

보는 것: 글이 바닥글을 침범하지 않는지 · 사진 칸이 세로로 넘치지 않는지 · 캡션이 두 줄이 되지 않았는지 · 표지 글이 잘리지 않았는지. 고치면 다시 ④→⑤.

## 8. 앱에 붙일 때

### 우리 다이어리(diary)
- 데이트 코스 · 먹을 곳 · 잘 곳 · '우리 집' 후보 카드의 사진은 **앱의 기존 사진 저장 방식(암호화 묶음 · 사진 id)**을 따른다. `k.json`을 새로 만들지 않고 기존 사진 id를 바꾸지 않는다(CLAUDE.md).
- 앱 안에 돈 · 가격은 넣지 않는다(재준 규칙). 캡션은 장소 · 영업시간 · 휴무까지만.
- 코스 PDF를 통째로 넣을 땐 4쪽 PDF 그대로(폰에서 열린다). 카드 한 장짜리면 사진 1장 + 한 줄 캡션.
- 소재 조사(매주 새 소재 · 데이트 코스 24 등)에서 사진이 필요하면 위 ②→③ 그대로. 출처는 카드 작은 글씨.

### 업무보고(upmoo)
- 쓰는 곳: 설계 완료 **제안서 PDF**(사진 첨부) · 🚗 **동선 지도 그림 한 장** · **바뀐 기능 설명서 · 튜토리얼**의 실제 화면 사진 · 장소 사진이 필요한 안내문.
- 화면 사진은 연습 모드(가짜 자료)로 찍는다(기존 규칙). 외부 장소 사진은 3-B로.
- PDF는 저장소의 기존 `mk_*.py` 파이프라인(Pretendard · 끝 줄 '넘친 쪽 없음')이 있으면 그걸 쓰고, 사진 넣는 방식(프레임 크롭 · 캡션 띠 · 출처 줄)만 이 문서대로.

## 9. 자주 터지는 것 · 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 사진 URL curl 403 | 샌드박스 정책 | 3-B Canva 우회. 재시도 · 미러 · 캐시 금지 |
| PDF 쪽 수가 늘어남 | 사진 칸 세로 넘침 | 프레임 37mm 유지 · 캡션 한 줄 · 사진 6장 이하 |
| 페이지가 78% 크기 | wkhtmltopdf mm 축소 | `_wk.html`에 `body{zoom:1.282}` |
| 한글이 □로 나옴 | 글꼴 없음 | Noto Sans CJK KR 설치 · font-family 확인 |
| reportlab TTFError | OTF(CFF) 글꼴 | reportlab 대신 HTML → PDF |
| Canva 썸네일이 338px | read-design 썸네일 | 그 쪽에 `replace_speaker_notes` 편집 → 600px |
| 정규식으로 자리 표시를 바꾸니 다른 블록까지 날아감 | `.*?</div>\s*</div>` 처럼 넓게 잡음 | `<div class="placeholder"><span>.*?</span></div>` 또는 `<!--PHOTO:…-->` 한 줄로 |
| 표지 글이 바닥글 침범 | 글 많음 | 글자 1pt 줄이기 · 항목 2개 빼기 |
